# ai-excited-01 — Molten-Gold Phoenix

A molten-gold phoenix bursting from a storm sea: liquid-gold feathers,
flying embers, lightning overhead, dark teal waves below.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `image.png` to `out/entry.png`, byte for byte.
Python 3.13 standard library only; no network, no randomness.
